# Contenuti da verificare

Elenco delle affermazioni nautiche presenti nel gioco (lezioni, quiz, glossario), da confrontare con un manuale di vela o con un istruttore. Le ha scritte un'intelligenza artificiale, e chi parte da zero non può accorgersi di un errore: serve un controllo esterno.

**Come usarla:** parti dalla sezione «Dubbi specifici». Se il manuale conferma una riga, non serve fare nulla. Se dice altro, annotalo accanto alla riga: poi vanno corretti insieme gioco, glossario e quiz.

Colonna «Esito»: ✅ confermato · ❌ diverso (scrivi cosa dice il manuale) · ❓ non trovato.

## Dubbi specifici, da controllare per primi

| Punto | Cosa dice il gioco | Perché c'è un dubbio | Esito |
| --- | --- | --- | --- |
| Strambata e abbattuta | Sono sinonimi | Alcuni testi chiamano abbattuta la manovra voluta e strambata quella involontaria. | ❓ La dispensa della Scuola Vela Argentario usa «abbattuta» per la manovra; resta da capire se «strambata» sia usata anche per quella voluta. |
| Confini delle andature | Angolo morto fino a circa 40° (testi: «circa 45° per lato»), bolina 40–75°, traverso 75–105°, lasco 105–135°, gran lasco 135–165°, poppa oltre 165° | Valori indicativi, variano con la barca. | ✅ Allineato alle dispense: 90° in tutto (45° per lato) come convenzione didattica (Scuola Vela Argentario, Mediterranea Sailing); circa 70° per le derive (Lega Navale, «A vela sulla deriva»). Versione 0.13. |
| Posizione dei filetti | Due filetti sulla randa, vicino all'albero | Sulla randa i filetti classici stanno sulla balumina; quelli vicino all'inferitura sono tipici del fiocco. | ❓ La regola di lettura è confermata dalla Lega Navale («cazzare se il filetto tende sopravvento, lascare se tende sottovento»); la posizione resta da verificare. |
| Colori dei filetti | Rosso sul lato sinistro, verde sul lato destro | Scelta del gioco, ispirata ai fanali; sulle vele reali i colori variano. | |
| Comandi di manovra | «Pronti a virare?», «Pronti!», «Viro!»; «Pronti a strambare?», «Strambo!» | D'uso comune, ma con varianti tra scuole. | |
| Precedenza tra mure | Tra due barche a vela con mure diverse, quella mure a sinistra lascia strada | Regola del regolamento per prevenire gli abbordi in mare; il gioco tratta anche il caso delle stesse mure (lascia strada la barca sopravento). | |
| Orziera | Barca che tende a salire da sola verso il vento | Usato nell'esercizio di rotta; verificare il termine. | |

## Lezione 1: parti della barca e termini base

| Termine | Cosa dice il gioco | Esito |
| --- | --- | --- |
| Deriva (barca) | Piccola barca a vela senza cabina, con lama di deriva mobile; quella su cui di solito si impara. | |
| Deriva (lama) | Lama sotto lo scafo che impedisce alla barca di essere spinta di lato; dà il nome alle derive. | |
| Prua, poppa | Parte anteriore e posteriore. | |
| Dritta, sinistra | Lato destro e sinistro guardando verso prua; appartengono alla barca. | |
| Albero, boma, randa | Palo che regge la vela; asta orizzontale del lato basso della vela; vela principale. | |
| Scotta, cima | Cima che regola la vela; a bordo le corde si chiamano cime. | |
| Timone, barra | Pala a poppa che fa girare la barca; manico con cui la si comanda. | |
| Vento da nord | Il vento si indica dalla direzione da cui arriva. | |
| Sopravento, sottovento | Lato colpito per primo dal vento; lato riparato. Boma sottovento, timoniere sopravento. | |
| Orzare, poggiare | Prua verso il vento; prua lontano dal vento. | |
| Cazzare, lascare | Tirare la scotta (vela verso il centro); mollarla (vela aperta). | |
| Angolo morto | Settore attorno alla direzione del vento in cui la vela non spinge. | |
| Fileggiare, stallo | Vela che sbatte perché troppo lascata; vela troppo cazzata che non lavora. | |
| Nodo | Un miglio nautico all'ora, 1,852 km/h. | |

## Lezione 2: il timone

| Affermazione | Esito |
| --- | --- |
| La prua gira dalla parte opposta a quella in cui si spinge la barra. | |
| Barra sottovento, la barca orza; barra sopravento, la barca poggia. | |
| Ogni angolo di barra frena la barca: meglio piccole correzioni fatte presto. | |
| Andando all'indietro, l'effetto della barra si inverte. | |

## Lezione 3: andature, mure, filetti

| Affermazione | Esito |
| --- | --- |
| Ordine delle andature: bolina (stretta e larga), traverso, lasco, gran lasco, poppa. | |
| Al traverso la vela va aperta circa a metà: boma a una quarantina di gradi dal centro barca. | |
| La poppa non è l'andatura più veloce; lo sono traverso e lasco (per una deriva che non plana). | |
| Mure a dritta se il vento arriva da destra; il boma sta dal lato opposto alle mure. | |
| Filetto sopravento agitato: cazza o poggia. Filetto sottovento agitato: lasca o orza. | |
| «Orzi e cazzi, poggi e laschi». | |
| Superando i 180° in poppa con la vela tutta aperta si stramba, e spesso si scuffia. | |

## Lezione 4: vento reale e apparente

| Affermazione | Esito |
| --- | --- |
| Il vento apparente combina vento reale e vento dovuto al moto; è quello su cui lavora la vela. | |
| Accelerando, il vento apparente si sposta verso prua: bisogna cazzare. | |
| In poppa il vento apparente è più debole del reale, di bolina più forte. | |

## Lezione 5: virata e strambata

| Affermazione | Esito |
| --- | --- |
| Virata: prua attraverso il vento. Strambata: poppa attraverso il vento. | |
| Si vira con la barca lanciata; senza abbrivio la barca si pianta e poi arretra. | |
| In bolina, su una deriva a una vela, la randa resta cazzata su entrambe le mure. | |
| Bordeggiare: risalire il vento a zig-zag; ogni tratto è un bordo. | |
| Strambata controllata: cazzare fino a circa 45°, poggiare finché il vento passa dall'altro lato, poi lascare. | |

## Lezione 6: raffiche, sbandamento, scuffia

| Affermazione | Esito |
| --- | --- |
| Le raffiche si vedono arrivare da sopravento come acqua più scura e increspata. | |
| In raffica si lasca; di bolina si può anche orzare di poco. | |
| Il timoniere si sporge fuori bordo, sopravento, contro lo sbandamento. | |
| Si raddrizza salendo sulla lama di deriva e facendo leva col proprio peso. | |

## Regate

| Affermazione | Esito |
| --- | --- |
| Allo scadere del conto alla rovescia bisogna essere dietro la linea; chi è oltre deve tornare indietro. | |
| Tra barche con le stesse mure, lascia strada quella sopravento. | |
| La procedura reale di partenza dura 5 minuti (il gioco permette anche 1 e 3). | |
| Nelle regate il lato da cui lasciare le boe lo stabiliscono le istruzioni di regata; di solito si lasciano a sinistra (il gioco le lascia sempre a sinistra, anche nelle prove). | |
| Chi gira una boa dal lato sbagliato può rimediare tornando indietro e rifacendo il giro: il percorso della barca, immaginato come un filo teso, deve passare dal lato giusto di ogni boa (regola del «filo teso» del regolamento di regata). | |
| Toccare una boa in regata comporta una penalità (nel gioco non è ancora gestito). | |
